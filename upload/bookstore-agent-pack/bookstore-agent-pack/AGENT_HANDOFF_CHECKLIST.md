# Agent Handoff Checklist

Use this when giving the pack to a coding agent.

## Before coding

- [ ] Open the target project/repository.
- [ ] Add or attach this whole Markdown pack to the agent's context.
- [ ] Paste `MASTER_CODING_AGENT_PROMPT.md` as the primary instruction.
- [ ] Ensure the agent can inspect and edit the repository, run terminal commands, and access current project files.

## Values the agent must keep configurable

- [ ] Store name/logo/domain
- [ ] Contact and support details
- [ ] Book catalogue/price/stock/real cover images
- [ ] Licensed PDF assets and preview assets
- [ ] Payment provider/merchant details/callback URLs
- [ ] Courier provider, delivery zones/fees and tracking configuration
- [ ] Shipping, cancellation, returns/refunds, privacy and digital access policy
- [ ] Transactional email settings
- [ ] Download defaults and admin access setup

## Before launch

- [ ] Replace all demo content and remove sample sales/orders/reviews.
- [ ] Confirm distribution rights for every PDF/eBook.
- [ ] Set production environment variables securely.
- [ ] Complete payment-provider onboarding and test verified server callbacks.
- [ ] Test private storage and denied-download scenarios.
- [ ] Configure support, delivery, refund and privacy policies.
- [ ] Verify production admin bootstrap, backups, monitoring and email sender.
- [ ] Complete QA acceptance criteria and controlled mobile checkout test.
