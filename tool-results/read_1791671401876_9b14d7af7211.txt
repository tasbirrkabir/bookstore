    19→    19→## Domain decisions
    20→    20→
    21→    21→- Variant = cart line identity (`physical` | `digital` | `bundle`).
    22→    22→- Order status separate from payment_status. COD only for physical-only carts. Digital/mixed → online payment.
    23→    23→- Stock committed atomically (conditional update) at: order confirmation (COD) / verified payment (online). Restock on cancel per policy.
    24→    24→- Entitlement granted only on verified payment (idempotent, unique per orderItem+asset). Download endpoint: ownership OR guest capability token (sha256-hashed at rest), paid check, active/expiry/count/revocation checks, atomic increment + audit events, rate limited. Server-side streaming (short-lived delivery, nothing persisted).
    25→    25→- Admin = User.role === 'admin', checked server-side on every admin API + layout guard. Bootstrap via seed script using ADMIN_EMAIL/ADMIN_PASSWORD env.
    26→    26→- Guest orders: high-entropy capability token; order number shown but never sole authorization.
